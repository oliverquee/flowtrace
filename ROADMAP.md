# FlowTrace Roadmap

FlowTrace is a local-first Python code/workflow analyzer that compares intended flow, static structure, and runtime behavior.

## Completed Versions

- V0.1: Code to static/runtime report
- V0.1.1: Real-project hardening basics
- V0.1.2: Static-only safety mode and runtime diagnostics
- V0.1.3: Summary-first risk-ranked markdown report
- V0.1.4: Opt-in runtime variable-change capture (--capture-variables)
- V0.2: Lightweight local HTML report viewer (in progress; not stable until merged)

## Next Planned Versions

- V0.1.5: CLI command profiling / target args reporting
- V0.1.6: Static vs runtime comparison improvements
- V0.3: Intended-flow comparison improvements
- V0.4: Version-to-version trace comparison
- V0.5: Visual flow editor

## Out Of Current Scope

- UI
- SaaS
- AI integration
- Database
- Plugin system
- Multi-language support
